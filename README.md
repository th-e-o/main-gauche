# Main gauche jazz

Appli web pour travailler la conduite de voix à la main gauche au piano jazz : voicings sans fondamentale (formes A/B), shells et notes guides, sur des ii–V–I, des standards et tes propres grilles. Elle peut écouter ton piano au micro pour vérifier tes accords.

En ligne : https://th-e-o.github.io/main-gauche/
